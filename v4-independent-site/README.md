# Independent Living Codex V4 source

This is a one-time frozen copy of the actual live V2.87 application, not a redesigned interface or an automatic rebuild from V2.

The V4 source is in index.html, css/ and js/. Edit those files directly. No original archive or historical patch tooling is required.

Run a local static web server in this folder: python -m http.server 8765 --bind 127.0.0.1 and open http://127.0.0.1:8765/ .

Original lore, calendar and curated demo content were removed. Some setting-specific UI strings remain and need to be audited. Remaining offline RPCs and the campaign-specific native creator are not fully implemented yet.
